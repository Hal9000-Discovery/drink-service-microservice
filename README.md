# Drink Service Microservice

A Flask-based microservice that manages drink and price data with SQL Server integration.  
Built for learning microservice architecture with Docker, Playwright, and AI integration.

---

## 🚀 Features
- RESTful API endpoints for managing drinks and prices  
- Microsoft SQL Server backend (local or containerized)  
- `/health` endpoint for Docker/Kubernetes monitoring  
- Dockerized deployment with `python:3.13-slim` base image  
- Extensible design for Postman, JMeter, and Playwright automation  
- Optional AI Agent integration (OpenAI API)
